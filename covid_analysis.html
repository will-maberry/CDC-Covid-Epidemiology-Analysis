1 Study Data

This study uses a 10,000-record sample of reported COVID-19 cases restricted to the early pre-vaccine study period from March 15 through December 10, 2020.

Data were downloaded from the CDC COVID-19 Case Surveillance Public Use Data through the CDC Socrata API.

A reproducible computational subsample was constructed by randomly selecting 20 calendar dates within the study period using a fixed random seed (42). For each selected date, up to 500 records were retrieved from a contiguous block of surveillance records, with the starting position selected reproducibly using a date-specific random seed. Records were ordered by their internal Socrata identifier before retrieval.

The resulting dataset contains 10,000 surveillance records and 12 variables. Since sampling was performed by date and contiguous record blocks rather than by simple random sampling across all eligible cases, the sample should not be considered representative of all reported COVID-19 cases during the study period.

3.2 Risk Ratio and Risk Difference

Here \(a\) and \(b\) represent hospitalized and non-hospitalized exposed cases, respectively. Similarly, \(c\) and \(d\) represent hospitalized and non-hospitalized unexposed cases, respectively. The crude risk ratio (RR) and risk difference (RD) are defined as:

\[RR=\frac{a/(a+b)}{c/(c+d)} \qquad RD=\frac{a}{a+b}-\frac{c}{c+d}\]

Hospitalization risk is estimated separately among exposed and unexposed cases.

Code 
# Extract cells from exposure-outcome table
a <- exposure_outcome["Yes", "Yes"]
b <- exposure_outcome["Yes", "No"]
c <- exposure_outcome["No", "Yes"]
d <- exposure_outcome["No", "No"]

# Hospitalization risks
risk_exposed <- a / (a + b)
risk_unexposed <- c / (c + d)

# Effect measures
risk_ratio <- risk_exposed / risk_unexposed
risk_difference <- risk_exposed - risk_unexposed

# Display hospitalization risks and effect measures
round(c(
    Risk_Exposed = risk_exposed,
    Risk_Unexposed = risk_unexposed,
    Risk_Ratio = risk_ratio,
    Risk_Difference = risk_difference
), 3)
   Risk_Exposed  Risk_Unexposed      Risk_Ratio Risk_Difference 
          0.353           0.036           9.860           0.317

Among cases in the complete-case analytic cohort, hospitalization was reported for 35.3% of individuals with a reported pre-existing medical condition and 3.6% of individuals without one. The crude risk ratio was 9.86, indicating that the proportion hospitalized was approximately 9.86 times as high among individuals with reported medical conditions. The crude risk difference was 31.7 percentage points, representing the absolute difference in hospitalization proportions between the two groups.

3.3 95% Confidence Interval for Risk Ratio

A 95% confidence interval (CI) for the crude risk ratio was calculated using the normal approximation to the log-tranformed risk ratio. The standard error of the log risk ratio is estimated as:

\[ SE[\ln(RR)] = \sqrt{ \frac{1}{a} - \frac{1}{a+b} + \frac{1}{c} - \frac{1}{c+d} } \]

The confidence interval is calculated on the logarithmic scale and then exponentiated to return to the risk-ratio scale.

\[ 95\% CI_{RR} = \exp[ \ln(RR) \pm 1.96 \times SE[\ln(RR)] ] \]

Code 
# Standard error of the log risk ratio
se_log_rr <- sqrt(
    (1 / a) - (1 / (a + b)) +
    (1 / c) - (1 / (c + d))
)

# Calculate confidence limits on log scale
log_rr <- log(risk_ratio)

log_rr_lower <- log_rr - (1.96 * se_log_rr)
log_rr_upper <- log_rr + (1.96 * se_log_rr)

# Transform confidence limits back to risk-ratio scale
rr_lower <- exp(log_rr_lower)
rr_upper <- exp(log_rr_upper)

round(c(
    RR = risk_ratio,
    Lower_95_CI = rr_lower,
    Upper_95_CI = rr_upper
), 3)
         RR Lower_95_CI Upper_95_CI 
      9.860       6.719      14.470

The crude risk ratio was 9.86 (95% CI: 6.72–14.47). The confidence interval excludes the null value of 1, indicating evidence of a positive crude association between reported pre-existing medical condition and hospitalization.

3.4 95% Confidence Interval for Risk Difference

A 95% confidence interval for the crude risk difference was calculated using the normal approximation for the difference between two independent proportions. The standard error is estimated as:

\[ SE(RD) = \sqrt{ \frac{R_1(1-R_1)}{n_1} + \frac{R_0(1-R_0)}{n_0} } \]

Here, \(R_1\) and \(R_0\) represent the observed hospitalization proportions among exposed and unexposed cases, respectively, while \(n_1\) and \(n_0\) represent the corresponding group sizes.

The confidence interval is calculated directly on the risk-difference scale:

\[ 95\% CI_{RD} = RD \pm 1.96 \times SE(RD) \]

Code 
# Group sample sizes
n_exposed <- a + b
n_unexposed <- c + d

# Standard error of risk difference
se_rd <- sqrt(
    (risk_exposed * (1 - risk_exposed) / n_exposed) +
    (risk_unexposed * (1 - risk_unexposed) / n_unexposed)
)

# Calculate confidence limits
rd_lower <- risk_difference - (1.96 * se_rd)
rd_upper <- risk_difference + (1.96 * se_rd)

round(c(
    RD = risk_difference,
    Lower_95_CI = rd_lower,
    Upper_95_CI = rd_upper
), 3)
         RD Lower_95_CI Upper_95_CI 
      0.317       0.279       0.354

The crude risk difference was 31.7 percentage points (95% CI: 27.9–35.4 percentage points). The confidence interval excludes the null value of 0, indicating evidence of a positive crude difference in hospitalization proportions between reported pre-existing medical condition and hospitalization.

These estimates describe crude, unadjusted associations and do not account for potential confounding by age or sex. Both confidence intervals were calculated using the normal approximation, which may be inaccurate for small sample sizes or extreme proportions.

4.3 Summary of Potential Confounders

The descriptive comparisons were used to examine the relationships of age and sex with both reported pre-existing medical conditions and hospitalization. Differences in these distributions may contribute to the observed crude association.

Age and sex were retained as adjustment variables based on the hypothesized causal structure and prior literature review rather than solely on the descriptive results. The following adjusted analysis examines the exposure-outcome association while accounting for these variables.

5.2.1 Interpretation of Logistic Regression

Logistic regression models the log odds of a binary outcome as a function of the exposure and adjustment varialbes. The fitted model can be written as:

\[ \beta_0 + \beta_E E_i + \sum_{k=1}^{8}\beta_{A_k}A_{ik} + \beta_S S_i, \]

where

\[ p_i = P(Y_i = 1 \mid E_i, A_i, S_i). \]

Here, \(E_i\) represents reported pre-existing medical condition status, \(A_{ik}\) represents the eight indicator variables from the non-reference age groups, and \(S_i\) represents sex.

The exposure coefficient \(\beta_E\) represents the difference in conditional log odds of hospitalization between cases with and without reported pre-existing medical conditions, holding age group and sex constant.

6 Statistical Uncertainty and Bootstrap Inference

The nonparametric bootstrap approximates the sampling distribution of a statistic by repeatedly drawing samples with replacement from the observed data. The variability of the resulting estimates can be used to quantify sampling uncertainty.

6.1 Resampling the Analytic Cohort

Each bootstrap sample contains the same number of observations as the original analytic cohort. However, because sampling occurs with replacement, some observations appear multiple times while others are not selected.

For a dataset containing \(n\) observations, the probability that a specific observation is not selected in a single draw is:

\[ 1-\frac{1}{n}. \]

The probability that a specific observation is never selected across \(n\) independent draws is:

\[ P(\text{not selected}) = (1-\frac{1}{n})^n. \]

The bootstrap standard error is calculated as the sample standard deviation of the \(B\) bootstrap estimates:

\[ \widehat{\mathrm{SE}}_{\mathrm{boot}}(\hat p) = \sqrt{ \frac{1}{B-1} \sum_{b=1}^{B} (\hat p^{*(b)}-\bar p^*)^2 }. \]

\[ CI_{95\%} = [ Q_{0.025}(\hat{p}^{*}), Q_{0.975}(\hat{p}^{*}) ]. \]

6.2.2 Recalculating Standardized Estimates

To extend bootstrap inference to the adjusted risk ratio (RR) and adjusted risk difference (RD), regression standardization must be applied to each of the 100 fitted bootstrap models.

For each bootstrap model, two exposure scenarios are constructed: one in which all cases are assigned reported pre-existing medical conditions and another in which all cases are assigned no reported pre-existing medical conditions. Age and sex remain unchanged.

Predicted hospitalization probabilities are averaged across the corresponding bootstrap sample to obtain standardized hospitalization proportions.

For bootstrap replication \(b\), the standardized hospitalization proportion under exposure condition \(e\) is:

\[ \hat{p}_{e}^{*(b)} = \frac{1}{n} \sum_{i=1}^{n} \widehat{P}^{*(b)} (Y_i=1\mid E_i=e,A_i^{*(b)},S_i^{*(b)}). \]

The adjusted risk ratio and risk difference are then calculated as:

\[ \widehat{RR}^{*(b)} = \frac{\hat{p}_{1}^{*(b)}}{\hat{p}_{0}^{*(b)}} \]

\[ \widehat{RD}^{*(b)} = \hat{p}_{1}^{*(b)}-\hat{p}_{0}^{*(b)}. \]

Repeating this procedure across the previously fitted bootstrap models produces empirical distributions of the standardized measures of association.

## Risk Ratio and Risk Difference

Here $a$ and $b$ represent hospitalized and non-hospitalized exposed cases, respectively. Similarly, $c$ and $d$ represent hospitalized and non-hospitalized unexposed cases, respectively. The crude risk ratio (RR) and risk difference (RD) are defined as:

$$RR=\frac{a/(a+b)}{c/(c+d)} \qquad RD=\frac{a}{a+b}-\frac{c}{c+d}$$

Hospitalization risk is estimated separately among exposed and
unexposed cases.

```{r}

b <- exposure_outcome["Yes", "No"]
c <- exposure_outcome["No", "Yes"]
d <- exposure_outcome["No", "No"]

# Hospitalization risks
risk_exposed <- a / (a + b)
risk_unexposed <- c / (c + d)

# Effect measures

risk_difference <- risk_exposed - risk_unexposed

# Display hospitalization risks and effect measures

The crude risk ratio was `r round(risk_ratio, 2)`, indicating that the proportion hospitalized was approximately `r round(risk_ratio, 2)` times as high among individuals with reported medical conditions. The crude risk difference was `r round(risk_difference * 100, 1)` percentage points, representing the absolute difference in hospitalization proportions between the two groups.

## 95% Confidence Interval for Risk Ratio

A 95% confidence interval (CI) for the crude risk ratio was calculated using the normal approximation to the log-tranformed risk ratio. The standard error of the log risk ratio is estimated as:

$$
SE[\ln(RR)] =
\sqrt{
    \frac{1}{a}
    - \frac{1}{a+b}
    + \frac{1}{c}
    - \frac{1}{c+d}
}
$$

The confidence interval is calculated on the logarithmic scale and then exponentiated to return to the risk-ratio scale.

$$
95\% CI_{RR} =
\exp[
    \ln(RR) \pm 1.96 \times SE[\ln(RR)]
]
$$

```{r}
# Standard error of the log risk ratio
se_log_rr <- sqrt(
    (1 / a) - (1 / (a + b)) +
    (1 / c) - (1 / (c + d))
)

# Calculate confidence limits on log scale
log_rr <- log(risk_ratio)

log_rr_lower <- log_rr - (1.96 * se_log_rr)
log_rr_upper <- log_rr + (1.96 * se_log_rr)

# Transform confidence limits back to risk-ratio scale
rr_lower <- exp(log_rr_lower)
rr_upper <- exp(log_rr_upper)

round(c(
    RR = risk_ratio,
    Lower_95_CI = rr_lower,
    Upper_95_CI = rr_upper
), 3)
```

The crude risk ratio was `r round(risk_ratio, 2)` (95% CI: `r round(rr_lower, 2)`--`r round(rr_upper, 2)`). The confidence interval excludes the null value of 1, indicating evidence of a positive crude association between reported pre-existing medical condition and hospitalization.

## 95% Confidence Interval for Risk Difference

A 95% confidence interval for the crude risk difference was calculated using the normal approximation for the difference between two independent proportions. The standard error is estimated as:

$$
SE(RD) =
\sqrt{
    \frac{R_1(1-R_1)}{n_1}
    + \frac{R_0(1-R_0)}{n_0}
}
$$

Here, $R_1$ and $R_0$ represent the observed hospitalization proportions among exposed and unexposed cases, respectively, while $n_1$ and $n_0$ represent the corresponding group sizes.

The confidence interval is calculated directly on the risk-difference scale:

$$
95\% CI_{RD} = RD \pm 1.96 \times SE(RD)
$$

```{r}
# Group sample sizes
n_exposed <- a + b
n_unexposed <- c + d

# Standard error of risk difference
se_rd <- sqrt(
    (risk_exposed * (1 - risk_exposed) / n_exposed) +
    (risk_unexposed * (1 - risk_unexposed) / n_unexposed)
)

# Calculate confidence limits
rd_lower <- risk_difference - (1.96 * se_rd)
rd_upper <- risk_difference + (1.96 * se_rd)

round(c(
    RD = risk_difference,
    Lower_95_CI = rd_lower,
    Upper_95_CI = rd_upper
), 3)
```

The crude risk difference was `r round(risk_difference * 100, 1)` percentage points (95% CI: `r round(rd_lower * 100, 1)`--`r round(rd_upper * 100, 1)` percentage points). The confidence interval excludes the null value of 0, indicating evidence of a positive crude difference in hospitalization proportions between reported pre-existing medical condition and hospitalization.

These estimates describe crude, unadjusted associations and do not account for potential confounding by age or sex. Both confidence intervals were calculated using the normal approximation, which may be inaccurate for small sample sizes or extreme proportions.

### Interpretation of Logistic Regression

Logistic regression models the log odds of a binary outcome as a function of the exposure and adjustment varialbes. The fitted model can be written as:

$$
\beta_0 + \beta_E E_i + \sum_{k=1}^{8}\beta_{A_k}A_{ik} + \beta_S S_i,
$$

where

$$
p_i = P(Y_i = 1 \mid E_i, A_i, S_i).
$$

Here, $E_i$ represents reported pre-existing medical condition status, $A_{ik}$ represents the eight indicator variables from the non-reference age groups, and $S_i$ represents sex.

The exposure coefficient $\beta_E$ represents the difference in conditional log odds of hospitalization between cases with and without reported pre-existing medical conditions, holding age group and sex constant.

$$

$$

$$
95\% CI_{OR} =
\exp(
    \hat{\beta}_E \pm 1.96 \times SE(\hat{\beta}_E)
)
$$

# Extract the coefficient variance and calculate its standard error

# Statistical Uncertainty and Bootstrap Inference

The nonparametric bootstrap approximates the sampling distribution of a statistic by repeatedly drawing samples with replacement from the observed data. The variability of the resulting estimates can be used to quantify sampling uncertainty.

## Resampling the Analytic Cohort

Each bootstrap sample contains the same number of observations as the original analytic cohort. However, because sampling occurs with replacement, some observations appear multiple times while others are not selected.

Maintaining the original sample size allows the bootstrap procedure to approximate how an estimator would vary across repeated samples of that size, using the observed data as an empirical approximation to the underlying population distribution.

```{r}
# Set random seed for reproducibility
set.seed(42)

# Number of observations in adjusted-analysis cohort
n <- nrow(adjusted_analysis)

# Draw n row indices with replacement
bootstrap_indices <- sample(
    x = seq_len(n),
    size = n,
    replace = TRUE
)

# Construct a bootstrap sample
bootstrap_sample <- adjusted_analysis[
    bootstrap_indices,
]

# Compare sample sizes
nrow(adjusted_analysis)
nrow(bootstrap_sample)
```

For a dataset containing $n$ observations, the probability that a specific observation is not selected in a single draw is:

$$
1-\frac{1}{n}.
$$

The probability that a specific observation is never selected across $n$ independent draws is:

$$
P(\text{not selected}) = (1-\frac{1}{n})^n.
$$

As $n$ becomes large, this approaches $e^{-1} \approx 0.368$. As a result, the probability that an observation appears at least once is roughly $1-e^{-1}\approx 0.632$.

```{r}
# Unique observations selected
n_unique <- length(unique(bootstrap_indices))

# Proportion of original observations represented
prop_unique <- n_unique / n

n_unique
prop_unique

# Count how many times each original observation appears
selection_counts <- tabulate(
    bootstrap_indices,
    nbins = n
)

# Frequency distribution of selection counts
table(selection_counts)


# Original hospitalization distribution
prop.table(table(adjusted_analysis$hospitalized))

# Bootstrap hospitalization distribution
prop.table(table(bootstrap_sample$hospitalized))

```


### Constructing a Bootstrap Distribution

A single bootstrap sample demonstrates how sampling with replacement changes the composition of the analytic cohort. However, estimating sampling variability requires repeated resampling and recalculation of the statistic of interest for each bootstrap sample.

```{r}
# Examine hospitalization variable
class(adjusted_analysis$hospitalized)

levels(adjusted_analysis$hospitalized)

table(adjusted_analysis$hospitalized)

# Verify the proportion
mean(adjusted_analysis$hospitalized == "Yes")
```

We first examine the overall hospitalization proportion. The observed hospitalization proportion is defined as:

$$
\hat{p} = \frac{1}{n}\sum_{i=1}^{n}Y_i,
$$

where $Y_i=1$ indicates hospitalization for case $i$, $Y_i=0$ indicates no hospitalization, and $n$ is the number of cases in the analytic cohort.

For each boostrap replication $b$, we draw $n$ case records with replacement and recalculate the hospitalization proportion, producing $\hat{p}^{*(b)}$. Repeating this process $B$ times yields an empirical bootstrap distribution of the estimator.

```{r}
# Original hospitalization proportion
original_prop <- mean(adjusted_analysis$hospitalized == "Yes")

original_prop


set.seed(42)

# Number of bootstrap replications
B <- 1000

# Store hospitalization proportions
bootstrap_props <- numeric(B)

# Repeat the resampling process
for (b in seq_len(B)) {

    # Sample observations with replacement
    indices <- sample(

    # Calculate hospitalization proportion

        boot_data$hospitalized == "Yes"
    )
}

The bootstrap standard error is calculated as the sample standard deviation of the $B$ bootstrap estimates:

$$
\widehat{\mathrm{SE}}_{\mathrm{boot}}(\hat p)
=
\sqrt{
\frac{1}{B-1}
\sum_{b=1}^{B}
(\hat p^{*(b)}-\bar p^*)^2
}.
$$

Here, $\hat p^{*(b)}$ represents the estimated hospitalization proportion from bootstrap replication $b$, and $\bar p^*$ is the mean of the bootstrap estimates.

Unlike the standard deviation of individual hospitalization outcomes, which describes variation across cases, the bootstrap standard error describes variation in the estimated hospitalization proportion across resamples.

We can also construct a 95% percentile bootstrap confidence interval by identifying the 2.5th and 97.5th percentiles of the bootstrap distribution:

$$
CI_{95\%} =
[
Q_{0.025}(\hat{p}^{*}),
Q_{0.975}(\hat{p}^{*})
].
$$

This approach uses the empirical distribution of the bootstrap estimates rather than assuming that the distribution is exactly normal.

## Refitting the Regression Model

Unlike the overall hospitalization proportion, the regression-standardized estimates depend on coefficients estimated from the observed data. If the composition of the analytic cohort changes, the fitted regression coefficients may also change.

As a result, each bootstrap replication must repeat the model-fitting procedure rather than reuse the coefficients estimated from the original cohort.

For each bootstrap replication, we draw a sample of $n$ case records with replacement and refit the same logistic regression model. Repeating this procedure produces bootstrap distributions of the estimated regression coefficients.

These distributions reflect how the fitted coefficients vary across resamples of the observed analytic cohort, conditional on the resampling assumptions.

```{r}
# Set seed for reproducibility

    # Draw case records with replacement
    indices <- sample(
        x = seq_len(n),
        size = n,
        replace = TRUE
    )

    # Construct bootstrap dataset
    boot_data <- adjusted_analysis[indices, , drop = FALSE]

    # Refit logistic regression model
    boot_model <- glm(
        hospitalized ~ medcond + age_factor + sex_factor,

    )

    # Store exposure coefficient if model converged

    all(is.finite(coef(boot_model)))) {

        bootstrap_beta[b] <- unname(coef(boot_model)[exposure_term])

    }
}

### Recalculating Standardized Estimates

To extend bootstrap inference to the adjusted risk ratio (RR) and adjusted risk difference (RD), regression standardization must be applied to each of the `r B_model` fitted bootstrap models.

For each bootstrap model, two exposure scenarios are constructed: one in which all cases are assigned reported pre-existing medical conditions and another in which all cases are assigned no reported pre-existing medical conditions. Age and sex remain unchanged.

Predicted hospitalization probabilities are averaged across the corresponding bootstrap sample to obtain standardized hospitalization proportions.

For bootstrap replication $b$, the standardized hospitalization proportion under exposure condition $e$ is:

$$
\hat{p}_{e}^{*(b)}
=
\frac{1}{n}
\sum_{i=1}^{n}
\widehat{P}^{*(b)}
(Y_i=1\mid E_i=e,A_i^{*(b)},S_i^{*(b)}).
$$

The adjusted risk ratio and risk difference are then calculated as:

$$
\widehat{RR}^{*(b)}
=
\frac{\hat{p}_{1}^{*(b)}}{\hat{p}_{0}^{*(b)}}
$$

$$
\widehat{RD}^{*(b)}
=
\hat{p}_{1}^{*(b)}-\hat{p}_{0}^{*(b)}.
$$

Repeating this procedure across the previously fitted bootstrap models produces empirical distributions of the standardized measures of association.

### Calculating Standardized Estimates

```{r}
# Store standardized estimates from existing bootstrap models
bootstrap_rr <- rep(NA_real_, B_model)
bootstrap_rd <- rep(NA_real_, B_model)

bootstrap_risk_exposed <- rep(NA_real_, B_model)
bootstrap_risk_unexposed <- rep(NA_real_, B_model)

# Use previously fitted models and their corresponding samples
for (b in seq_len(B_model)) {

    boot_model <- bootstrap_models[[b]]
    boot_data <- bootstrap_samples[[b]]

    # Skip unsuccessful model fits
    if (is.null(boot_model) || is.null(boot_data)) {
        next
    }

    # Construct exposure scenarios
    exposed <- boot_data
    unexposed <- boot_data

    exposed$medcond <- factor(
        "Yes",
        levels = levels(adjusted_analysis$medcond)
    )

    unexposed$medcond <- factor(
        "No",
        levels = levels(adjusted_analysis$medcond)
    )

    # Predict hospitalization probabilities
    p_exposed <- predict(
        boot_model,
        newdata = exposed,
        type = "response"
    )

    p_unexposed <- predict(
        boot_model,
        newdata = unexposed,
        type = "response"
    )

    # Standardize over the bootstrap sample
    risk_exposed <- mean(p_exposed)
    risk_unexposed <- mean(p_unexposed)

    if (
        !is.finite(risk_exposed) ||
        !is.finite(risk_unexposed) ||
        risk_unexposed <= 0
    ) {
        next
    }

    # Store standardized proportions
    bootstrap_risk_exposed[b] <- risk_exposed
    bootstrap_risk_unexposed[b] <- risk_unexposed

    # Calculate adjusted measures
    bootstrap_rr[b] <- risk_exposed / risk_unexposed
    bootstrap_rd[b] <- risk_exposed - risk_unexposed
}

# Examine successful replications
sum(is.finite(bootstrap_rr) & is.finite(bootstrap_rd))

summary(bootstrap_rr)
summary(bootstrap_rd)
```

Each successful bootstrap replication produces a standardized hospitalization proportion for both exposure scenarios, along with an adjusted RR and RD.

Due to the models being fitted to different resampled cohorts, the resulting estimates vary across replications. This variability reflects changes in the fitted regression coefficients and the empirical distribution of age and sex.
