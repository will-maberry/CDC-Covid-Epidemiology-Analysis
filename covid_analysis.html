2 Analytic Cohort

The analysis is restricted to cases with known exposure and outcome status. Exposure is defined by medcond_yn, indicating whether a pre-existing medical condition was reported. The outcome is defined by hosp_yn, indicating a hospitalization was reported.

medcond_yn and hosp_yn are coded as {Yes, No, Unknown, Missing}. Only Yes and No records for either the exposure or outcome are kept for the complete-case analysis.

Code 
analysis <- covid[
    covid$medcond_yn %in% c("Yes", "No") &
    covid$hosp_yn %in% c("Yes", "No"),
]

3.3 95% Confidence Interval for Risk Ratio

The conventional Wald confidence interval for the risk ratio is defined as:

\[ SE[\ln(RR)] = \sqrt{ \frac{1}{a} -\frac{1}{a+b} +\frac{1}{c} -\frac{1}{c+d} } \]

Code 
se_log_rr <- sqrt(
    (1 / a) - (1 / (a + b)) +
    (1 / c) - (1 / (c + d))
)

log_rr <- log(risk_ratio)

log_rr_lower <- log_rr - (1.96 * se_log_rr)
log_rr_upper <- log_rr + (1.96 * se_log_rr)

rr_lower <- exp(log_rr_lower)
rr_upper <- exp(log_rr_upper)

c(
    RR = risk_ratio,
    Lower_95_CI = rr_lower,
    Upper_95_CI = rr_upper
)
         RR Lower_95_CI Upper_95_CI 
   9.860001    6.718710   14.469983

The crude risk ratio was 9.86 (95% CI: 6.72–14.47).

3.4 95% Confidence Interval for Risk Difference

For two independent proportions the standard error is defined as:

\[ SE(RD) = \sqrt{ \frac{R_1(1-R_1)}{n_1} + \frac{R_0(1-R_0)}{n_0} } \]

Code 
n_exposed <- a + b
n_unexposed <- c + d

se_rd <- sqrt(
    (risk_exposed * (1 - risk_exposed) / n_exposed) +
    (risk_unexposed * (1 - risk_unexposed) / n_unexposed)
)

rd_lower <- risk_difference - (1.96 * se_rd)
rd_upper <- risk_difference + (1.96 * se_rd)

c(
    RD = risk_difference,
    Lower_95_CI = rd_lower,
    Upper_95_CI = rd_upper
)
         RD Lower_95_CI Upper_95_CI 
  0.3168477   0.2792667   0.3544287

The crude risk difference was 31.7 percentage points (95% CI: 27.9–35.4 percentage points).

These estimates are crude and unadjusted. These confidence intervals treat observations as independent.

5.1 Logistic Regression

A multivariable logistic regression model was fit with hospitalization as the outcome, reported pre-existing medical condition as the exposure, and age group and sex as prespecified adjustment variables.

The logistic model estimates conditional log odds of hospitalization. Exponentiated coefficients therefore represent adjusted odds ratios rather than adjusted risk ratios.

5.1.1 Logistic regression limitations

Our outcome is binary, so logistic regression is an obvious modeling choice. However, the logit link models the log odds of the outcome rather than the risk directoy. The fitted model can be written as:

\[ \operatorname{logit}(p_i) = \beta_0 + \beta_E E_i + \sum_{k=1}^{8}\beta_{A_k}A_{ik} + \beta_S S_i, \]

where

\[ p_i = P(Y_i = 1 \mid E_i, A_i, S_i). \]

Here, \(E_i\) represents reported pre-existing medical condition stuatus, \(A_{ik}\) represents the eight indicator variables from the non-reference age groups, and \(S_i\) represents sex.

The exposure coefficient \(\beta_E\) is estimated on the log-odds scale. Exponentiating this coefficient gives the adjusted odds ratio:

\[ OR_{\text{adjusted}} = e^{\beta_E}, \]

rather than an adjusted risk ratio, which was selected as teh primary measure for this analysis. Consequently, the adjusted risk ratio will be estimated from the fitted logistic regression model using regression standardization.
