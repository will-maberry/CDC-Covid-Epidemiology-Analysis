Analytic Cohort

The analysis is restricted to cases with known exposure and outcome status. Exposure is defined by medcond_yn, indicating whether a pre-existing medical condition was reported. The outcome is defined by hosp_yn, indicating a hospitalization.

The record label set is {Yes, No, Unknown, Missing}. Only Yes and No records for either the exposure or outcome are kept for the complete-case analysis.

analysis <- covid[
    covid$medcond_yn %in% c("Yes", "No") &
    covid$hosp_yn %in% c("Yes", "No"),
]

dim(analysis)
[1] 1464   12

The resulting complete-case analytic cohort contains 1,464 cases.

Risk Ratio and Risk Difference

Hospitalization risk is estimated separately among exposed and unexposed cases.

# Extract cells from exposure-outcome table
a <- exposure_outcome["Yes", "Yes"]
b <- exposure_outcome["Yes", "No"]
c <- exposure_outcome["No", "Yes"]
d <- exposure_outcome["No", "No"]

# Hospitalization risks
risk_exposed <- a / (a + b)
risk_unexposed <- c / (c + d)

# Effect measures
risk_ratio <- risk_exposed / risk_unexposed
risk_difference <- risk_exposed - risk_unexposed

Among cases in the complete-case analytic cohort, hospitalization risk was approximately 35.3% among those with a reported pre-existing medical condition and 3.6% among those without one. The crude risk ratio was 9.86, corresponding to an absolute risk difference of approximately 31.7 percentage points.

95% Confidence Interval for Risk Ratio

The conventional Wald confidence interval for the risk ratio is defined as:

\[ SE[\ln(RR)] = \sqrt{ \frac{1}{a} -\frac{1}{a+b} +\frac{1}{c} -\frac{1}{c+d} } \]

se_log_rr <- sqrt(
    (1 / a) - (1 / (a + b)) +
    (1 / c) - (1 / (c + d))
)

log_rr <- log(risk_ratio)

log_rr_lower <- log_rr - (1.96 * se_log_rr)
log_rr_upper <- log_rr + (1.96 * se_log_rr)

rr_lower <- exp(log_rr_lower)
rr_upper <- exp(log_rr_upper)

c(
    RR = risk_ratio,
    Lower_95_CI = rr_lower,
    Upper_95_CI = rr_upper
)
         RR Lower_95_CI Upper_95_CI 
   9.860001    6.718710   14.469983

The crude risk ratio was 9.86 (95% CI: 6.72-14.47).

95% Confidence Interval for Risk Difference

For two independent proportions the standard error is defined as:

\[ SE(RD) = \sqrt{ \frac{R_1(1-R_1)}{n_1} + \frac{R_0(1-R_0)}{n_0} } \]

n_exposed <- a + b
n_unexposed <- c + d

se_rd <- sqrt(
    (risk_exposed * (1 - risk_exposed) / n_exposed) +
    (risk_unexposed * (1 - risk_unexposed) / n_unexposed)
)

rd_lower <- risk_difference - (1.96 * se_rd)
rd_upper <- risk_difference + (1.96 * se_rd)

c(
    RD = risk_difference,
    Lower_95_CI = rd_lower,
    Upper_95_CI = rd_upper
)
         RD Lower_95_CI Upper_95_CI 
  0.3168477   0.2792667   0.3544287

The crude risk difference was 31.7 percentage points (95% CI: 27.9-35.4 percentage points).

These estimates are crude and unadjusted. These confidence intervals treat observations as independent.
