1 Study Data

This study uses a 10,000-record sample of reported COVID-19 cases restricted to the early pre-vaccine study period from March 15 through December 10, 2020.

The dataset for this study was acquired from the CDC COVID-19 Case Surveillance Public Use Data through the CDC Socrata API.

The study dataset is a computational subsample of and was constructed by randomly selecting 20 calendar dates within the study period using a fixed random seed (42). For each selected date, up to 500 records were retrieved from a contiguous block of surveillance records, with the starting position selected using a date-specific random seed. Records were ordered by their internal Socrata identifier before retrieval.

The resulting dataset contains 10,000 surveillance records and 12 variables. Since sampling was performed by date and contiguous record blocks rather than by simple random sampling across all eligible cases, the sample should not be considered representative of all reported COVID-19 cases during the study period.

2 Analytic Cohort

The analysis is restricted to cases with known exposure and outcome status. Exposure is defined by medcond_yn, indicating whether a pre-existing medical condition was reported. The outcome is defined by hosp_yn, indicating a hospitalization was reported.

medcond_yn and hosp_yn are coded as {Yes, No, Unknown, Missing}. Only Yes and No records for both variables were retained in the exposure-outcome complete-case cohort.

Code 
analysis <- covid[
    covid$medcond_yn %in% c("Yes", "No") &
    covid$hosp_yn %in% c("Yes", "No"),
]

cat(sprintf("Rows: %s | Columns: %s\n", 
    format(nrow(analysis), big.mark = ","), 
    format(ncol(analysis), big.mark = ",")))
Rows: 1,464 | Columns: 12

The resulting exposure-outcome complete-case cohort contained 1464 cases (14.64% of the original sample). The remaining 8536 cases (85.36%) were excluded because exposure status, hospitalization status, or both were not recorded as Yes or No.

3.2 Risk Ratio and Risk Difference

Here \(a\) and \(b\) represent hospitalized and non-hospitalized exposed cases, respectively. Similarly, \(c\) and \(d\) represent hospitalized and non-hospitalized unexposed cases, respectively. The crude risk ratio (RR) and risk difference (RD) are defined as:

\[ RR=\frac{a/(a+b)}{c/(c+d)} \qquad RD=\frac{a}{a+b}-\frac{c}{c+d} \]

Hospitalization risk is estimated separately among exposed and unexposed cases.

Code 
# Extract cells from exposure-outcome table
a <- exposure_outcome["Yes", "Yes"]
b <- exposure_outcome["Yes", "No"]
c <- exposure_outcome["No", "Yes"]
d <- exposure_outcome["No", "No"]

# Hospitalization risks
risk_exposed <- a / (a + b)
risk_unexposed <- c / (c + d)

# Effect measures
risk_ratio <- risk_exposed / risk_unexposed
risk_difference <- risk_exposed - risk_unexposed

# Display hospitalization risks and effect measures
results <- data.frame(
    Measure = c(
        "Risk in Exposed (reported medical condition)",
        "Risk in Unexposed (no reported medical condition)",
        "Risk Ratio (RR)",
        "Risk Difference (RD)"
    ),
    Value = c(
        sprintf("%.3f (%.1f%%)", risk_exposed, risk_exposed * 100),
        sprintf("%.3f (%.1f%%)", risk_unexposed, risk_unexposed * 100),
        sprintf("%.3f", risk_ratio),
        sprintf("%.3f (%+.1f pp)", risk_difference, risk_difference * 100)
    )
)

3.3 95% Confidence Interval for Risk Ratio

A 95% confidence interval (CI) for the crude risk ratio was calculated using the normal approximation to the log-transformed risk ratio. The standard error of the log risk ratio is estimated as:

\[ SE[\ln(RR)] = \sqrt{ \frac{1}{a} - \frac{1}{a+b} + \frac{1}{c} - \frac{1}{c+d} } \]

The confidence interval is calculated on the logarithmic scale and then exponentiated to return to the risk-ratio scale.

\[ 95\% CI_{RR} = \exp[ \ln(RR) \pm 1.96 \times SE[\ln(RR)] ] \]

Code 
# Standard error of the log risk ratio
se_log_rr <- sqrt(
    (1 / a) - (1 / (a + b)) +
    (1 / c) - (1 / (c + d))
)

# Calculate confidence limits on log scale
log_rr <- log(risk_ratio)

log_rr_lower <- log_rr - (1.96 * se_log_rr)
log_rr_upper <- log_rr + (1.96 * se_log_rr)

# Transform confidence limits back to risk-ratio scale
rr_lower <- exp(log_rr_lower)
rr_upper <- exp(log_rr_upper)

rr_summary <- data.frame(
    Estimate = sprintf("%.3f", risk_ratio),
    `95% CI Lower` = sprintf("%.3f", rr_lower),
    `95% CI Upper` = sprintf("%.3f", rr_upper),
    check.names = FALSE
)

knitr::kable(
    rr_summary,
    caption = "Risk Ratio (95% Confidence Interval)",
    align = c("l", rep("r", ncol(rr_summary) - 1)),
    booktabs = TRUE,
    row.names = FALSE
)
Risk Ratio (95% Confidence Interval)
Estimate 95% CI Lower 95% CI Upper
9.860 6.719 14.470

The crude risk ratio was 9.86 (95% CI: 6.72–14.47). The confidence interval excludes the null value of 1, indicating evidence of a positive crude association between reported pre-existing medical condition and hospitalization.

3.4 95% Confidence Interval for Risk Difference

A 95% confidence interval for the crude risk difference was calculated using the normal approximation for the difference between two independent proportions. The standard error is estimated as:

\[ SE(RD) = \sqrt{ \frac{R_1(1-R_1)}{n_1} + \frac{R_0(1-R_0)}{n_0} } \]

Here, \(R_1\) and \(R_0\) represent the observed hospitalization proportions among exposed and unexposed cases, respectively, while \(n_1\) and \(n_0\) represent the corresponding group sizes.

The confidence interval is calculated directly on the risk-difference scale:

\[ 95\% CI_{RD} = RD \pm 1.96 \times SE(RD) \]

Code 
# Group sample sizes
n_exposed <- a + b
n_unexposed <- c + d

# Standard error of risk difference
se_rd <- sqrt(
    (risk_exposed * (1 - risk_exposed) / n_exposed) +
    (risk_unexposed * (1 - risk_unexposed) / n_unexposed)
)

# Calculate confidence limits
rd_lower <- risk_difference - (1.96 * se_rd)
rd_upper <- risk_difference + (1.96 * se_rd)

rd_summary <- data.frame(
  Scale = c("Proportion", "Percentage Points (pp)"),
  Estimate = c(
    sprintf("%+.3f", risk_difference),
    sprintf("%+.2f pp", risk_difference * 100)
  ),
  `95% CI Lower` = c(
    sprintf("%+.3f", rd_lower),
    sprintf("%+.2f pp", rd_lower * 100)
  ),
  `95% CI Upper` = c(
    sprintf("%+.3f", rd_upper),
    sprintf("%+.2f pp", rd_upper * 100)
  ),
  check.names = FALSE
)

knitr::kable(
    rd_summary,
    caption = "Risk Difference (95% Confidence Interval)",
    align = c("l", rep("r", ncol(rd_summary) - 1)),
    booktabs = TRUE,

The crude risk difference was 31.7 percentage points (95% CI: 27.9–35.4 percentage points). The confidence interval excludes the null value of 0, indicating evidence of a positive crude difference in hospitalization proportions between reported pre-existing medical condition and hospitalization.

These estimates describe crude, unadjusted associations and do not account for potential confounding by age or sex. Both confidence intervals were calculated using the normal approximation, which may be inaccurate for small sample sizes or extreme proportions.

5.2 Logistic Regression

A multivariable logistic regression model was fitted to examine the association between reported pre-existing medical conditions and hospitalization while adjusting for age group and sex. Hospitalization was modeled as a binary outcome, with medical-condition status as the primary exposure and age group and sex included as categorical covariates.

5.2.1 Model Specification

The logistic regression model expresses the log-odds of hospitalization as a linear combination of the exposure and adjustment variables:

\[ \log(\frac{p_i}{1-p_i}) = \beta_0 + \beta_E E_i + \sum_{k=1}^{8}\beta{A_k}A_{ik}+\beta_S S_i, \]

where

\[ p_i = P(Y_i = 1 \mid E_i, A_i, S_i). \]

In the equation above, \(Y_i\) indicates hospitalization for case \(i\), \(E_i\) represents reported pre-existing medical-condition status, \(A_{ik}\) represents the eight indicator variables corresponding to non-reference age groups, and \(S_i\) represents sex.

The exposure coefficient \(\beta_E\) represents the difference in conditional log-odds of hospitalization between cases with and without reported pre-existing medical conditions, holding age group and sex constant.

\[_ RD_{\text{adjusted}} = \bar{p}_{E=1} - \bar{p}_{E=0}. \]

6 Statistical Uncertainty and Bootstrap Inference

The nonparametric bootstrap is a resampling method used to approximate the sampling distribution of a statistic. Rather than repeatedly collecting new datasets, the bootstrap generates samples from the observed data by randomly selecting observations with replacement.

In this analysis, bootstrap resampling is used to evaluate uncertainty in the hospitalization proportion and the regression-standardized measures of association.

6.1 Resampling the Analytic Cohort

Each bootstrap sample contains the same number of observations as the original analytic cohort. However, because sampling occurs with replacement, some observations appear multiple times while others are not selected.

Maintaining the original sample size allows the bootstrap procedure to approximate the variability of an estimator across repeated samples of the same size, using the empirical distribution of the observed cohort as the resampling distribution.

6.1.2 Observation Selection and Sample Composition

For a dataset containing \(n\) observations, the porbability that a particular observation is not selected in a single draw is:

\[ P(\text{not selected in one draw}) = 1-\frac{1}{n}. \]

Since a bootstrap sample consists of \(n\) independent draws with replacement, the probability that a particular observation is never selected is:

\[ P(\text{never selected}) = \left(1-\frac{1}{n}\right)^n. \]

As \(n\) becomes large, this probability approaches:

\[ \lim_{n\to\infty} \left(1-\frac{1}{n}\right)^n = e^{-1} \approx 0.368. \]

As a result, the probability that an observation appears at least once in a bootstrap sample approaches:

\[ P(\text{selected at least once}) = 1-e^{-1} \approx 0.632. \]

A typical bootstrap sample contains approximately \(63.2\)% of the original observations as distinct cases, with repeated selections accounting for the remaining positions.

6.1.4 Constructing a Bootstrap Distribution

The single bootstrap sample above demonstrates how sampling with replacement changes the composition of the analytic cohort. However, estimating sampling variability requires repeated resampling and recalculation of the statistic of interest for each bootstrap sample.

We first examine the overall hospitalization proportion in the adjusted analytic cohort. The observed hospitalization proportion is defined as:

\[ \hat{p} = \frac{1}{n} \sum_{i=1}^{n}Y_i, \]

where \(Y_i = 1\) indicates hospitalization for case \(i\), \(Y_i = 0\) indicates no hospitalization, and \(n\) represents the number of cases in the adjusted analytic cohort.

For each bootstrap replication \(b\), a sample of \(n\) cases is drawn with replacement and the hospitalization proportion is recalculated, producing \(\hat{p}^{*(b)}\). Repeating this process \(B\) times generates an empirical bootstrap distribution of the estimator.

6.1.4.2 Bootstrap Standard Error

The bootstrap standard error is calculated as the sample standard deviation of the \(B\) bootstrap estimates:

\[ \widehat{\mathrm{SE}}_{\mathrm{boot}}(\hat p) = \sqrt{ \frac{1}{B-1} \sum_{b=1}^{B} \left( \hat{p}^{*(b)}-\bar{p}^{*} \right)^2 }. \]

Here, \(\hat{p}^{*(b)}\) represents the hospitalization proportion estimated in bootstrap replication \(b\), and \(\bar{p}^{*}\) represents the mean of the bootstrap estimates.

Unlike the standard deviation of individual hospitalization outcomes, which describes variation across cases, the bootstrap standard error describes variation in the estimated hospitalization proportion across resamples.

6.2 Refitting the Regression Model

Unlike the overall hospitalization proportion, the regression-standardized estimates depend on coefficients estimated from the observed data. If the composition of the analytic cohort changes, the fitted regression coefficients may also change.

As a result, each bootstrap replication must repeat the model-fitting procedure rather than reuse the coefficients estimated from the original analytic cohort.

For each bootstrap replication, a sample of \(n\) case records is drawn with replacement, and the same multivariable logistic regression model is refitted. Repeating this procedure produces bootstrap distributions of the estimated regression coefficients.

The resulting distribution provides an empirical approximation to the sampling variability of the estimated log-odds ratio under the assumed case-level resampling procedure.

6.2.1 Generating Bootstrap Regression Models

Code

6.2.4 Recalculating Standardized Estimates

To extend bootstrap inference to the adjusted risk ratio (RR) and adjusted risk difference (RD), regression standardization was repeated for each successfully fitted bootstrap model.

For each replication, two exposure scenarios were constructed using the corresponding bootstrap sample. Medical-condition status was set to Yes for all cases in one scenario and No for all cases in the other, while age group and sex remained unchanged.

Predicted hospitalization probabilities were then generated from the corresponding bootstrap regression model and averaged across the bootstrap sample.

For bootstrap replication \(b\), the standardized hospitalization proportion under exposure condition \(e\) is:

\[ \hat{p}_{e}^{*(b)} = \frac{1}{n} \sum_{i=1}^{n} \widehat{P}^{*(b)} \left( Y_i=1 \mid E_i=e, A_i^{*(b)}, S_i^{*(b)} \right). \]

Here, \(\widehat{P}^{*(b)}\) denotes the predicted hospitalization probability from the regression model fitted in bootstrap replication \(b\), and \(A_i^{*(b)}\) and \(S_i^{*(b)}\) represent the age group and sex of the \(i\)th observation in that bootstrap sample.

The adjusted risk ratio and risk difference are recalculated as:

\[ \widehat{RR}^{*(b)} = \frac{\hat{p}_{1}^{*(b)}}{\hat{p}_{0}^{*(b)}}, \]

\[ \widehat{RD}^{*(b)} = \hat{p}_{1}^{*(b)} - \hat{p}_{0}^{*(b)}. \]

Repeating this procedure across bootstrap models produces empirical distributions of the standardized measures of association.

7 Conclusion

This analysis examined the association between reported pre-existing medical conditions and hospitalization among early-pandemic COVID-19 cases using a sample of CDC surveillance data from March 15 through December 10, 2020. Among cases with known exposure and hospitalization status, reported pre-existing medical conditions were associated with a substantially higher proportion of hospitalization. The crude risk ratio was 9.86 (95% CI: 6.72–14.47), with an absolute risk difference of 31.7 percentage points.

Adjustment for age and sex reduced the estimated magnitude of the association. Regression standardization produced an adjusted risk ratio of 3.82 (95% percentile bootstrap CI: 2.66–5.91) and an adjusted risk difference of 18.8 percentage points (95% percentile bootstrap CI: 14.9–22.8 percentage points). The difference between the crude and adjusted estimates illustrates the importance of accounting for potential confounders. These were identified as age and sex variables in the dataset.

Several limitations restrict the interpretation and generalizability of these findings. Only 14.64% of the original surveillance sample had known medical-condition and hospitalization status, which could influence selection bias from complete-case analysis. Additionally, the original sample was constructed using randomly selected reporting dates and contiguous record blocks rather than simple random sampling, limiting its representativeness. The regression model adjusted for age and sex but could not account for other potential confounders, and the bootstrap confidence intervals reflect uncertainty under independent case-level resampling rather than the original sampling design. Consequently, the results should not be generalized to all reported COVID-19 cases or interpreted as population-level hospitalization risks.

## 95% Confidence Interval for Risk Ratio

A 95% confidence interval (CI) for the crude risk ratio was calculated using the normal approximation to the log-transformed risk ratio. The standard error of the log risk ratio is estimated as:

$$
SE[\ln(RR)] =
\sqrt{
    \frac{1}{a}
    - \frac{1}{a+b}
    + \frac{1}{c}
    - \frac{1}{c+d}
}
$$

The confidence interval is calculated on the logarithmic scale and then exponentiated to return to the risk-ratio scale.

$$
95\% CI_{RR} =
\exp[
    \ln(RR) \pm 1.96 \times SE[\ln(RR)]
]
$$

```{r}
# Standard error of the log risk ratio
se_log_rr <- sqrt(
    (1 / a) - (1 / (a + b)) +
    (1 / c) - (1 / (c + d))
)

# Calculate confidence limits on log scale
log_rr <- log(risk_ratio)

log_rr_lower <- log_rr - (1.96 * se_log_rr)
log_rr_upper <- log_rr + (1.96 * se_log_rr)

# Transform confidence limits back to risk-ratio scale
rr_lower <- exp(log_rr_lower)
rr_upper <- exp(log_rr_upper)

rr_summary <- data.frame(
    Estimate = sprintf("%.3f", risk_ratio),
    `95% CI Lower` = sprintf("%.3f", rr_lower),
    `95% CI Upper` = sprintf("%.3f", rr_upper),
    check.names = FALSE
)
```

## 95% Confidence Interval for Risk Difference

A 95% confidence interval for the crude risk difference was calculated using the normal approximation for the difference between two independent proportions. The standard error is estimated as:

$$
SE(RD) =
\sqrt{
    \frac{R_1(1-R_1)}{n_1}
    + \frac{R_0(1-R_0)}{n_0}
}
$$

Here, $R_1$ and $R_0$ represent the observed hospitalization proportions among exposed and unexposed cases, respectively, while $n_1$ and $n_0$ represent the corresponding group sizes.

The confidence interval is calculated directly on the risk-difference scale:

$$
95\% CI_{RD} = RD \pm 1.96 \times SE(RD)
$$

```{r}
# Group sample sizes
n_exposed <- a + b
n_unexposed <- c + d

# Standard error of risk difference
se_rd <- sqrt(
    (risk_exposed * (1 - risk_exposed) / n_exposed) +
    (risk_unexposed * (1 - risk_unexposed) / n_unexposed)
)

# Calculate confidence limits
rd_lower <- risk_difference - (1.96 * se_rd)
rd_upper <- risk_difference + (1.96 * se_rd)

rd_summary <- data.frame(
```

## Logistic Regression

A multivariable logistic regression model was fitted to examine the association between reported pre-existing medical conditions and hospitalization while adjusting for age group and sex. Hospitalization was modeled as a binary outcome, with medical-condition status as the primary exposure and age group and sex included as categorical covariates.

### Model Specification

The logistic regression model expresses the log-odds of hospitalization as a linear combination of the exposure and adjustment variables:

$$
\log(\frac{p_i}{1-p_i}) = \beta_0 + \beta_E E_i + \sum_{k=1}^{8}\beta{A_k}A_{ik}+\beta_S S_i,
$$

where

$$
p_i = P(Y_i = 1 \mid E_i, A_i, S_i).
$$

In the equation above, $Y_i$ indicates hospitalization for case $i$, $E_i$ represents reported pre-existing medical-condition status, $A_{ik}$ represents the eight indicator variables corresponding to non-reference age groups, and $S_i$ represents sex.

The exposure coefficient $\beta_E$ represents the difference in conditional log-odds of hospitalization between cases with and without reported pre-existing medical conditions, holding age group and sex constant.

### Model Estimation


### Exposure Coefficient and Adjusted Odds Ratio


The coefficient for reported pre-existing medical conditions was extracted from the fitted model. Exponentiating this coefficient converts the estimated log-odds ratio to an adjusted odds ratio (OR):

$$
OR_{\mathrm{adj}} = \exp(\hat{\beta}_E).
$$

A 95% Wald confidence interval was calculated using the standard error of the exposure coefficient. The confidence limits were first constructed on the log-odds scale and then exponentiated:

$$
CI_{95\%}(OR_{\mathrm{adj}})
=
\left[
    \exp\left(\hat{\beta}_E - 1.96\,SE(\hat{\beta}_E)\right),
    \exp\left(\hat{\beta}_E + 1.96\,SE(\hat{\beta}_E)\right)
\right].
$$

## Regression Standardization

## Adjusted Risk Ratio and Risk Difference

The regression-standardized hospitalization proportions were used to calculate two measures of adjusted association: the risk ratio (RR) and risk difference (RD). Both measures compare model-predicted hospitalization proportions under the two exposure scenarios, standardized to the same age and sex distribution.

The adjusted risk ratio compares the relative difference between the standardized hospitalization proportions:

$$
RR_{\text{adjusted}} = \frac{\bar{p}{E=1}}{\bar{p}{E=0}},
$$

where $\bar{p}_{E=1}$ and $\bar{p}_{E=0}$ represent the mean model-predicted hospitalization probabilities under reported pre-existing medical conditions and no reported medical conditions, respectively.

The adjusted risk difference expresses the absolute difference between these proportions:

$$_
RD_{\text{adjusted}} = \bar{p}_{E=1} - \bar{p}_{E=0}.
$$

Unlike the risk ratio, which is expressed as a relative measure, the risk difference can be multiplied by 100 and interpreted in percentage points.

# Statistical Uncertainty and Bootstrap Inference

The nonparametric bootstrap is a resampling method used to approximate the sampling distribution of a statistic. Rather than repeatedly collecting new datasets, the bootstrap generates samples from the observed data by randomly selecting observations with replacement.

In this analysis, bootstrap resampling is used to evaluate uncertainty in the hospitalization proportion and the regression-standardized measures of association.

## Resampling the Analytic Cohort

Each bootstrap sample contains the same number of observations as the original analytic cohort. However, because sampling occurs with replacement, some observations appear multiple times while others are not selected.

Maintaining the original sample size allows the bootstrap procedure to approximate the variability of an estimator across repeated samples of the same size, using the empirical distribution of the observed cohort as the resampling distribution.

### Constructing a Bootstrap Sample

```{r}

    size = n,
    replace = TRUE
)

    bootstrap_indices,

    drop = FALSE

    `Dataset` = c(
        "Original Adjusted Cohort",
        "Bootstrap Sample"

        c(nrow(adjusted_analysis), nrow(bootstrap_sample)),
        big.mark = ","
    ),

    bootstrap_size_summary,
    caption = "Bootstrap Sample Size Comparison",
```

The original adjusted analytic cohort contained `r format(n, big.mark = ",")` observations. The bootstrap sample also contained `r format(nrow(bootstrap_sample), big.mark = ",")` observations, although the composition of the sample differed because individual cases could be selected more than once.

### Observation Selection and Sample Composition

For a dataset containing $n$ observations, the porbability that a particular observation is not selected in a single draw is:

$$
P(\text{not selected in one draw})
=
1-\frac{1}{n}.
$$

Since a bootstrap sample consists of $n$ independent draws with replacement, the probability that a particular observation is never selected is:

$$
P(\text{never selected})
=
\left(1-\frac{1}{n}\right)^n.
$$

As $n$ becomes large, this probability approaches:

$$
\lim_{n\to\infty}
\left(1-\frac{1}{n}\right)^n
=
e^{-1}
\approx 0.368.
$$

As a result, the probability that an observation appears at least once in a bootstrap sample approaches:

$$
P(\text{selected at least once})
=
1-e^{-1}
\approx 0.632.
$$

A typical bootstrap sample contains approximately $63.2$% of the original observations as distinct cases, with repeated selections accounting for the remaining positions.

### Constructing a Bootstrap Distribution

The single bootstrap sample above demonstrates how sampling with replacement changes the composition of the analytic cohort. However, estimating sampling variability requires repeated resampling and recalculation of the statistic of interest for each bootstrap sample.

We first examine the overall hospitalization proportion in the adjusted analytic cohort. The observed hospitalization proportion is defined as:

$$
\hat{p}
=
\frac{1}{n}
\sum_{i=1}^{n}Y_i,
$$

where $Y_i = 1$ indicates hospitalization for case $i$, $Y_i = 0$ indicates no hospitalization, and $n$ represents the number of cases in the adjusted analytic cohort.

For each bootstrap replication $b$, a sample of $n$ cases is drawn with replacement and the hospitalization proportion is recalculated, producing $\hat{p}^{*(b)}$. Repeating this process $B$ times generates an empirical bootstrap distribution of the estimator.


#### Bootstrap Standard Error

The bootstrap standard error is calculated as the sample standard deviation of the $B$ bootstrap estimates:

$$
\widehat{\mathrm{SE}}_{\mathrm{boot}}(\hat p)
=
\sqrt{
    \frac{1}{B-1}
    \sum_{b=1}^{B}
    \left(
    \hat{p}^{*(b)}-\bar{p}^{*}
    \right)^2
}.
$$

Here, $\hat{p}^{*(b)}$ represents the hospitalization proportion estimated in bootstrap replication $b$, and $\bar{p}^{*}$ represents the mean of the bootstrap estimates.

Unlike the standard deviation of individual hospitalization outcomes, which describes variation across cases, the bootstrap standard error describes variation in the estimated hospitalization proportion across resamples.

#### Percentile Bootstrap Confidence Interval

A 95% percentile bootstrap confidence interval was constructed using the 2.5th and 97.5th percentiles of the bootstrap distribution:

$$
CI_{95\%}
=
\left[
Q_{0.025}(\hat{p}^{*}),
Q_{0.975}(\hat{p}^{*})
\right].
$$

This approach uses the empirical distribution of bootstrap estimates to construct an interval without requiring an exactly normal sampling distribution.

However, percentile confidence intervals still depend on the bootstrap distribution adequately approximating the estimator's sampling behavior.

## Refitting the Regression Model

Unlike the overall hospitalization proportion, the regression-standardized estimates depend on coefficients estimated from the observed data. If the composition of the analytic cohort changes, the fitted regression coefficients may also change.

As a result, each bootstrap replication must repeat the model-fitting procedure rather than reuse the coefficients estimated from the original analytic cohort.

For each bootstrap replication, a sample of $n$ case records is drawn with replacement, and the same multivariable logistic regression model is refitted. Repeating this procedure produces bootstrap distributions of the estimated regression coefficients.

The resulting distribution provides an empirical approximation to the sampling variability of the estimated log-odds ratio under the assumed case-level resampling procedure.

### Generating Bootstrap Regression Models

```{r}
# Set random seed for reproducibility
set.seed(42)

# Number of observations in adjusted analytic cohort

# Initialize storage for fitted models and bootstrap samples

bootstrap_samples <- vector("list", B_model)

for (b in seq_len(B_model)) {

    # Sample case indices with replacement
    indices <- sample(
        x = seq_len(n),
        size = n,
        replace = TRUE
    )

    # Construct bootstrap dataset
    boot_data <- adjusted_analysis[
        indices,
        ,
        drop = FALSE
    ]

    # Refit logistic regression model
    boot_model <- tryCatch(
        suppressWarnings(
            glm(
                hospitalized ~ medcond + age_factor + sex_factor,
                data = boot_data,
                family = binomial(link = "logit")

        error = function(e) NULL

        exposure_term %in% names(coef(boot_model)) &&

            coef(boot_model)[exposure_term]
```

### Recalculating Standardized Estimates

To extend bootstrap inference to the adjusted risk ratio (RR) and adjusted risk difference (RD), regression standardization was repeated for each successfully fitted bootstrap model.

For each replication, two exposure scenarios were constructed using the corresponding bootstrap sample. Medical-condition status was set to `Yes` for all cases in one scenario and `No` for all cases in the other, while age group and sex remained unchanged.

Predicted hospitalization probabilities were then generated from the corresponding bootstrap regression model and averaged across the bootstrap sample.

For bootstrap replication $b$, the standardized hospitalization proportion under exposure condition $e$ is:

$$
\hat{p}_{e}^{*(b)}
=
\frac{1}{n}
\sum_{i=1}^{n}
\widehat{P}^{*(b)}
\left(
    Y_i=1 \mid E_i=e, A_i^{*(b)}, S_i^{*(b)}
\right).
$$

Here, $\widehat{P}^{*(b)}$ denotes the predicted hospitalization probability from the regression model fitted in bootstrap replication $b$, and $A_i^{*(b)}$ and $S_i^{*(b)}$ represent the age group and sex of the $i$th observation in that bootstrap sample.

The adjusted risk ratio and risk difference are recalculated as:

$$
\widehat{RR}^{*(b)}
=
\frac{\hat{p}_{1}^{*(b)}}{\hat{p}_{0}^{*(b)}},
$$

$$
\widehat{RD}^{*(b)}
=
\hat{p}_{1}^{*(b)} - \hat{p}_{0}^{*(b)}.
$$

Repeating this procedure across bootstrap models produces empirical distributions of the standardized measures of association.

### Calculating Standardized Estimates

```{r}
# Initialize storage for standardized bootstrap estimates
bootstrap_rr <- rep(NA_real_, B_model)
bootstrap_rd <- rep(NA_real_, B_model)

bootstrap_risk_exposed <- rep(NA_real_, B_model)
bootstrap_risk_unexposed <- rep(NA_real_, B_model)

# Apply regression standardization to stored bootstrap models
for (b in seq_len(B_model)) {

    # Retrieve fitted model and corresponding bootstrap sample
    boot_model <- bootstrap_models[[b]]
    boot_data <- bootstrap_samples[[b]]

    # Skip unsuccessful model fits
    if (is.null(boot_model) || is.null(boot_data)) {
        next
    }

    # Construct exposure scenarios
    exposed <- boot_data
    unexposed <- boot_data

    # Assign exposure status while preserving factor levels
    exposed$medcond <- factor(
        rep("Yes", nrow(boot_data)),
        levels = levels(adjusted_analysis$medcond)
    )

    unexposed$medcond <- factor(
        rep("No", nrow(boot_data)),
        levels = levels(adjusted_analysis$medcond)
    )

    # Predict hospitalization probabilities
    predictions <- tryCatch(
        list(
            exposed = predict(
                boot_model,
                newdata = exposed,
                type = "response"
            ),
            unexposed = predict(
                boot_model,
                newdata = unexposed,
                type = "response"
            )
        ),
        error = function(e) NULL
    )

    # Skip unsuccessful predictions
    if (is.null(predictions)) {
        next
    }

    # Standardize over the corresponding bootstrap sample
    risk_exposed <- mean(predictions$exposed)
    risk_unexposed <- mean(predictions$unexposed)

    # Verify finite, valid probabilities
    valid_risks <- is.finite(risk_exposed) &&
        is.finite(risk_unexposed) &&
        risk_exposed >= 0 &&
        risk_exposed <= 1 &&
        risk_unexposed > 0 &&
        risk_unexposed <= 1

    if (!valid_risks) {
        next
    }

    # Store standardized hospitalization proportions
    bootstrap_risk_exposed[b] <- risk_exposed
    bootstrap_risk_unexposed[b] <- risk_unexposed

    # Calculate standardized association measures
    bootstrap_rr[b] <- risk_exposed / risk_unexposed
    bootstrap_rd[b] <- risk_exposed - risk_unexposed
}

# Identify replications with valid estimates for both measures
valid_replicates <- is.finite(bootstrap_rr) &
    is.finite(bootstrap_rd)

n_valid_standardized <- sum(valid_replicates)
n_failed_standardized <- B_model - n_valid_standardized

    `Measure` = c(
        "Bootstrap Replications Attempted",
        "Valid Standardized Estimates",
        "Unsuccessful Replications",
        "Successful Replications (%)"
    ),
    `Value` = c(
        format(B_model, big.mark = ","),
        format(n_valid_standardized, big.mark = ","),
        format(n_failed_standardized, big.mark = ","),
        sprintf(
            "%.1f%%",
            100 * n_valid_standardized / B_model
        )
    ),
    check.names = FALSE
)

knitr::kable(
    standardization_summary,
    caption = "Bootstrap Regression Standardization Summary",
    align = c("l", rep("r", ncol(standardization_summary) - 1)),
    booktabs = TRUE,
    row.names = FALSE
)
```

# Conclusion

This analysis examined the association between reported pre-existing medical conditions and hospitalization among early-pandemic COVID-19 cases using a sample of CDC surveillance data from March 15 through December 10, 2020. Among cases with known exposure and hospitalization status, reported pre-existing medical conditions were associated with a substantially higher proportion of hospitalization. The crude risk ratio was `r sprintf("%.2f", risk_ratio)` (95% CI: `r sprintf("%.2f", rr_lower)`--`r sprintf("%.2f", rr_upper)`), with an absolute risk difference of `r sprintf("%.1f", risk_difference * 100)` percentage points.

Adjustment for age and sex reduced the estimated magnitude of the association. Regression standardization produced an adjusted risk ratio of `r sprintf("%.2f", adjusted_rr)` (95% percentile bootstrap CI: `r sprintf("%.2f", ci_rr[1])`--`r sprintf("%.2f", ci_rr[2])`) and an adjusted risk difference of `r sprintf("%.1f", adjusted_rd * 100)` percentage points (95% percentile bootstrap CI: `r sprintf("%.1f", ci_rd[1] * 100)`--`r sprintf("%.1f", ci_rd[2] * 100)` percentage points). The difference between the crude and adjusted estimates illustrates the importance of accounting for potential confounders. These were identified as age and sex variables in the dataset.

Several limitations restrict the interpretation and generalizability of these findings. Only `r sprintf("%.2f", known_both)`% of the original surveillance sample had known medical-condition and hospitalization status, which could influence selection bias from complete-case analysis. Additionally, the original sample was constructed using randomly selected reporting dates and contiguous record blocks rather than simple random sampling, limiting its representativeness. The regression model adjusted for age and sex but could not account for other potential confounders, and the bootstrap confidence intervals reflect uncertainty under independent case-level resampling rather than the original sampling design. Consequently, the results should not be generalized to all reported COVID-19 cases or interpreted as population-level hospitalization risks.
