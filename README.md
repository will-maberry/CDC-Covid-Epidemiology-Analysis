# Early-Pandemic COVID-19 Epidemiologic Analysis

This repository contains an epidemiologic study examining the association between reported pre-existing medical conditions and hospitalization among reported COVID-19 cases during the early pre-vaccine period (March 15–December 10, 2020).

I come from a computer science background, where I work with large datasets and predictive models. My prior work typically prioritizes predictive performance before fully considering the processes that generated the dataset used. This project deliberately inverts that framework as I move further into the interdisciplinary space between computation and classical epidemiology.

Rather than beginning with a statistical model, this analysis begins with the research question, study population, exposure and outcome definitions, potential sources of bias, causal structure, and literature-informed confounder selection. Statistical analysis stems from what I learned in that stage of the project.

With this study marking my first project of classical epidemiologic methods, I have published the notes produced throughout it. Incorrect initial assumptions have been kept with strikethroughs, followed by corrections and updated reasoning.

This repository is meant to present a reporducible epidemiologic analysis and document my learning process along the way.
